## 📌 Projetos em destaque

### [Radiadores Pinheiro](https://github.com/BryanPinheiro77/Radiadores-pinheiro-backend)
Sistema de gestão operacional desenvolvido sob medida para a oficina Radiadores Pinheiro, voltado para **estoque, vendas, reposição e processos internos**. Atuei no desenvolvimento do **back-end com Java + Spring Boot**, incluindo **autenticação stateless com JWT**, **Spring Security**, **regras de negócio**, **testes unitários**, **documentação com Swagger/OpenAPI** e **geração de PDF**.

**Stack:** Java, Spring Boot, Spring Security, JWT, PostgreSQL, Supabase, JPA/Hibernate, JUnit 5, Mockito, H2, Swagger/OpenAPI, OpenPDF

### [Barbearia Alvaro Santos](https://github.com/BryanPinheiro77/BarbeariaAlvaroSantos)
Sistema de agendamentos com painel administrativo criado para **automatizar o atendimento e reduzir processos manuais** da operação. Desenvolvi a **API REST**, a camada de **segurança com Spring Security + JWT**, integração com **Pix via Mercado Pago**, notificações automatizadas por **WhatsApp** e deploy da solução em produção.

**Stack:** Java, Spring Boot, Spring Security, JWT, PostgreSQL, Supabase, JPA/Hibernate, Mercado Pago, WAHA, Railway, Vercel, React

### [Finance Bot](https://github.com/BryanPinheiro77/FinanceBot-BackEnd)
Bot financeiro em desenvolvimento para **registro e consulta de movimentações financeiras por linguagem natural**, com foco em **interpretação de mensagens**, **regras de negócio**, **organização de dados** e evolução incremental da inteligência do sistema.

**Stack:** Java, Spring Boot, PostgreSQL, Docker, Telegram Bot API
